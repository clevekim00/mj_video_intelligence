01

Set up once.

Already set up? Go to the next step. Open only the instructions you need.

Required · Install the Python tools

Start in the project folder with Python 3.11+. These commands use a macOS or Linux shell.

python3 -m venv .venv
source .venv/bin/activate
python -m pip install -e '.[youtube,asr]'
mj-video doctor

Transcribing a file also needs ffmpeg and ffprobe. On macOS with Homebrew:

brew install ffmpeg

doctor checks your setup. Check the youtube/asr flags and ffmpeg/ffprobe paths. Caption collection needs no analysis model. In a new terminal, run source .venv/bin/activate again.

For Codex · Install the skill

The skill tells Codex how to carry out the task. Copy it once, separately from the Python installation.

mkdir -p "${CODEX_HOME:-$HOME/.codex}/skills"
test ! -e "${CODEX_HOME:-$HOME/.codex}/skills/video-analysis" && \
  cp -R skills/video-analysis "${CODEX_HOME:-$HOME/.codex}/skills/video-analysis"

An existing skill folder is left untouched. Start a new Codex task after installing, then use $video-analysis. Run it with the Python environment prepared above.

For information extraction · Connect a model

To extract places, products, prices, or other information, connect a running model server.

export VIDEO_MODEL_BASE_URL=http://127.0.0.1:11434/v1
export VIDEO_MODEL_NAME=your-installed-model
mj-video doctor --check-model

Replace your-installed-model with the actual model ID on your server, and adjust the server address. These commands do not install a model or start its server.

The server must support OpenAI-compatible /chat/completions and JSON object responses. If modelError appears, check the connection. Using a remote server sends transcripts to that server.

04

If you get stuck.

YouTube has no captions

This tool does not download YouTube video files. Provide a local video or audio file containing speech. For a 429 error, wait before retrying.

Can it read text on screen?

The CLI and skill currently use captions and speech. Screen text and object analysis (OCR/vision) are not implemented. “Full” means all collected transcript chunks.

The first transcription is slow

The first run downloads the Whisper speech model (tiny by default). Once cached, local transcription can run offline. The default run limit is 900 seconds; adjust it with --timeout.

A repeated command fails

Each run needs a new output folder. Change analysis-output-01 to analysis-output-02. For model problems, run mj-video doctor --check-model.

I want to try the demo with buttons

With Docker ready, run these commands from the project folder.

cd demo
docker compose up --build

Open localhost:5173 in a browser. The default demo uses rules or transcript excerpts without a model; its results differ from model analysis. Read the demo guide
