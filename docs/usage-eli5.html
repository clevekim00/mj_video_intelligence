01

처음 한 번, 준비해요.

이미 준비했다면 다음 단계로 가세요. 필요한 항목만 펼쳐 보세요.

필수 · Python 도구 설치

프로젝트 폴더에서 시작해요. Python 3.11 이상이 필요해요. 아래 명령은 macOS·Linux 터미널 기준이에요.

python3 -m venv .venv
source .venv/bin/activate
python -m pip install -e '.[youtube,asr]'
mj-video doctor

파일의 말소리를 글로 바꾸려면 ffmpeg와 ffprobe도 필요해요. macOS에서 Homebrew를 쓰고 있다면:

brew install ffmpeg

doctor는 준비물 검사예요. youtube·asr는 설치 여부, ffmpeg·ffprobe는 경로를 확인하세요. 자막만 모으면 모델 설정이 없어도 괜찮아요. 새 터미널에서는 source .venv/bin/activate를 다시 실행해요.

Codex에서 쓸 때 · skill 설치

skill은 Codex가 작업 순서를 읽는 설명서예요. 위 Python 설치와 별도로 한 번 복사해요.

mkdir -p "${CODEX_HOME:-$HOME/.codex}/skills"
test ! -e "${CODEX_HOME:-$HOME/.codex}/skills/video-analysis" && \
  cp -R skills/video-analysis "${CODEX_HOME:-$HOME/.codex}/skills/video-analysis"

이미 설치된 폴더가 있으면 복사하지 않아요. 설치 후 새 Codex 작업에서 $video-analysis를 사용하세요. 실행할 때 위 Python 환경을 사용해야 해요.

내용까지 분석할 때 · 모델 연결

“장소·제품·가격을 찾아줘”처럼 내용을 정리하려면, 실행 중인 모델 서버를 연결해요.

export VIDEO_MODEL_BASE_URL=http://127.0.0.1:11434/v1
export VIDEO_MODEL_NAME=your-installed-model
mj-video doctor --check-model

your-installed-model은 내 서버에 설치된 실제 모델 ID로 바꾸세요. 주소도 내 서버에 맞춰요. 이 명령이 모델을 설치하거나 서버를 켜 주지는 않아요.

OpenAI 호환 /chat/completions와 JSON 객체 응답을 지원해야 해요. modelError가 나오면 연결을 확인하세요. 외부 서버 주소를 쓰면 자막이 그 서버로 전송돼요.

1
report.md → 읽기 쉬운 요약

출력 폴더에서 열어 결과를 빠르게 읽어요.

2
result.json → 자세한 결과

상태, 분석 범위, 경고, 근거를 확인해요. 자막만 모으면 transcript에 담겨요.

3
원문 → 답이 맞는지 확인

시간이 붙어 있어도 오해나 전사 오류는 있을 수 있어요.

completed

요청한 작업을 마쳤어요. 모든 사실을 찾았다는 뜻은 아니에요.

needs_input

쓸 수 있는 자막이 없어요. 말소리가 있는 파일이 필요해요.

failed

작업이 실패했어요. 설치·파일·모델 연결을 점검해요.

04

막히면 여기부터 보세요.

YouTube 자막이 없대요

이 도구는 YouTube 영상 파일을 내려받지 않아요. 말소리가 있는 로컬 영상·음성 파일을 제공하세요. 429 오류라면 잠시 뒤 다시 시도해요.

화면 속 글자도 읽나요?

현재 CLI·skill은 자막과 말소리를 다뤄요. 화면 글자·사물 분석(OCR·비전)은 아직 지원하지 않아요. “전체”도 모은 자막 전체를 뜻해요.

파일 전사가 처음엔 느려요

처음에는 Whisper 음성 인식 모델을 내려받아요. 기본값은 tiny예요. 준비가 끝나면 로컬 파일 전사는 오프라인으로도 가능해요. 기본 실행 제한은 900초이며 터미널의 --timeout으로 조절해요.

같은 명령을 다시 실행했는데 실패해요

출력 폴더는 매번 새 이름이어야 해요. analysis-output-01을 analysis-output-02로 바꾸세요. 모델 오류라면 mj-video doctor --check-model로 점검해요.

버튼이 있는 데모 화면으로 써 보고 싶어요

Docker가 준비되어 있다면 프로젝트 폴더에서 실행하세요.

cd demo
docker compose up --build
